# メモアプリ

このプロジェクトは、ユーザー登録とログイン機能を持つシンプルなメモアプリケーションです。

## 機能

- ユーザー登録
- ログイン
- メモの追加
- メモの表示
- メモの削除

## 実行方法

Python 3.14 以上が必要です。

```bash
python main.py
```

## ファイル構造

- `main.py`: メインのアプリケーションコード
- `script.py`: サンプルスクリプト
- `users.json`: ユーザー情報を保存するファイル（自動生成）
- `memo.json`: メモデータを保存するファイル（自動生成）

## 使用方法

1. プログラムを実行すると、メインメニューが表示されます。
2. ユーザー登録を選択してアカウントを作成します。
3. ログインしてメモ機能を操作します。

## 工夫した点
JSON読み込み時にNoneが返る場合があり、エラーが発生したため、Noneの場合は空の辞書で初期化する処理を追加しました。
